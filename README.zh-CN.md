# HP Compaq dc7900 BIOS / SPI Flash 恢复

[English](README.md) | [简体中文](README.zh-CN.md)

这是一次针对 HP Compaq dc7900 BIOS / SPI Flash 相关故障进行完整诊断并最终成功修复的技术记录。

本仓库记录从故障分析到最终恢复的完整过程，包括硬件识别、SPI Flash 访问、固件读取、二进制分析与比较、外置编程器操作、写入验证以及最终实机恢复。

本项目的目标并不是简单提供一个可供直接刷写的固件文件，而是建立一套可以理解、验证并复现的故障诊断与恢复方法。

## 项目状态

**已完成 —— 已在真实硬件上成功修复并验证。**

本仓库将整理并发布完整技术报告、实物照片、二进制分析、验证数据以及恢复流程。

## 重要提示

在没有确认以下信息之前，**不要直接把本项目中的任何固件镜像写入另一台机器：**

- 主板版本
- SPI Flash 芯片型号及容量
- 固件布局
- 机器唯一数据
- 原始固件备份的完整性
- 是否具备恢复和重新编程能力

如果使用了错误的镜像或者错误的写入方法，SPI Flash 编程可能导致主板完全无法启动。

在对芯片进行任何修改或者写入之前，都应该至少读取并保存多份原始固件，并验证这些备份的数据是否完全一致。

## 固件文件

固件二进制文件将在确认其内容后单独决定是否公开。

完整 SPI Flash 镜像中可能同时包含厂商固件以及与具体机器相关的唯一信息。因此，在确认其内容、再分发问题以及设备特定数据之前，本仓库不会直接发布完整二进制镜像。

无论最终是否公开完整 BIN 文件，本仓库都会提供：

- 文件哈希
- 固件结构分析
- 修改位置与修改内容
- 修复逻辑
- 可以复现的恢复方法
